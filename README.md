# Titanic Classification Analysis using Machine Learning

## Project Overview
This project performs a classification analysis to predict the survival of passengers aboard the Titanic using machine learning algorithms. The dataset used is the Titanic dataset, commonly available on platforms like Kaggle. The project involves data preprocessing, feature engineering, model training, evaluation, and visualization of results.

### Objectives
- Predict passenger survival (0 = Not Survived, 1 = Survived) using machine learning.
- Implement and compare multiple classification models: Logistic Regression, Decision Tree, Support Vector Machine (SVM), and K-Nearest Neighbors (KNN).
- Perform data cleaning, feature engineering, and visualization to gain insights.

## Dataset
The Titanic dataset contains passenger information such as:
- **Target Variable**: Survived (0 = Not Survived, 1 = Survived)
- **Features**: Pclass, Sex, Age, Fare, FamilySize, IsAlone, Embarked, Title

The dataset is loaded from a CSV file (`titanic.csv`) and includes 891 rows and 12 columns.

## Methodology
1. **Data Loading and Exploration**:
   - Load the Titanic dataset using `pandas`.
   - Display basic information (shape, first few rows) to understand the data.

2. **Data Cleaning**:
   - Handle missing values:
     - Fill missing `Age` with median.
     - Fill missing `Embarked` with mode.
     - Fill missing `Fare` with median.

3. **Feature Engineering**:
   - Create `FamilySize` (`SibSp + Parch + 1`).
   - Create `IsAlone` (1 if `FamilySize == 1`, else 0).
   - Extract and simplify `Title` from the `Name` column using regex.

4. **Data Preprocessing**:
   - Encode categorical variables (`Sex`, `Embarked`, `Title`) using `LabelEncoder`.
   - Split data into training (70%) and testing (30%) sets.
   - Apply `StandardScaler` for feature scaling.

5. **Model Training and Evaluation**:
   - Train four models: Logistic Regression, Decision Tree, SVM, and KNN.
   - Evaluate models using:
     - Accuracy
     - Precision
     - Recall
     - F1 Score
     - Classification Report
     - Confusion Matrix
     - ROC Curve (for models with probability predictions)
   - Perform cross-validation to assess model stability.

6. **Visualization**:
   - Generate a bar chart (`model_comparison.png`) to compare model performance metrics.
   - Plot ROC curves for models with probability predictions.

## Results
- **Model Performance** (based on test en test set):
  - **SVM**: Highest accuracy (~84%), precision (~84%), recall (~84%), and F1 score (~83%).
  - **Logistic Regression**: Accuracy (~79%), precision (~79%), recall (~79%), F1 score (~79%).
  - **KNN**: Accuracy (~79%), precision (~79%), recall (~79%), F1 score (~79%).
  - **Decision Tree**: Accuracy (~78%), precision (~77%), recall (~78%), F1 score (~77%).
- SVM outperformed other models, likely due to its ability to handle non-linear relationships in the data.
- Cross-validation scores indicate model stability, with SVM showing the least variance.
